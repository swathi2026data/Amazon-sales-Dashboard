# Amazon Sales Analysis Dashboard | Power BI

## Project Overview
This project focuses on analyzing Amazon sales data using Microsoft Power BI. An interactive dashboard was developed to understand sales performance and identify important business insights.

## Project Objectives
- Analyze Amazon sales data.
- Monitor key sales performance indicators.
- Identify sales trends and patterns.
- Present business insights through interactive visualizations.

## Tools & Technologies
- Microsoft Power BI
- Data Analysis
- Data Visualization
- Dashboard Development
